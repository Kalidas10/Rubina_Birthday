# Rubina_Birthday 💖✨

A luxury romantic storytelling archive and celebration website created for **Rubina's (Tudi) 18th Birthday** on October 7th.

Created with love by **Prakash**.

---

## 🌟 Highlights & Features

- **Midnight Birthday Experience**: Floating balloons, music player, interactive wish candles, and heartfelt video tribute.
- **Romantic Interactive Timeline**: Moments, voice clips, memory lane photo cards, and love story archive.
- **Audio & Video Memories**: Dedicated audio clips, voice notes, and celebration videos.
- **Responsive & Modern Design**: Styled with modern typography, smooth animations, and rich aesthetic palettes.

---

## 🚀 How to Run Locally

1. Clone or download this repository:
   ```bash
   git clone https://github.com/Kalidas10/Rubina_Birthday.git
   ```
2. Open `index.html` directly in any modern web browser, or double-click `start_website.bat`.
